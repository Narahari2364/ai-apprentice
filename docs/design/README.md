# UI design · AI Apprentice

**Designed by Marissa Ma ([@NingchenMa](https://github.com/NingchenMa))** · UI & experience, 3 October 2026

Mock-ups for all three modules, built on the team demo script (meal expenses in Ledgerline) and the challenge brief. Each image has numbered design notes on the right explaining the decisions.

Design rules:
- The Apprentice lives inside Ledgerline as a popup, not a side panel, so the expert keeps the full screen.
- Same style as Ledgerline (Roboto, square corners, its buttons), but the Apprentice uses its own **indigo** so you can always tell the agent apart from the software.
- No timers or counters on screen; the expert starts the session and can go off the record any time.
- Every screen labels its mode: Learning, Review or Teaching.
